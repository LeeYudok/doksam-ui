# DESIGN.md — 제철과일 판매 모바일앱 (4화면 정적 목업)

## 원형 (archetype)

**주 원형: `wizard-flow`** (과제 지정 — 고정값)

뼈대: 상단 단계 표시기(stepper, 1 탐색 → 2 상품 → 3 장바구니 → 4 완료) → 본문은
현재 단계 하나만 한 칼럼으로 → 하단 고정 이전/다음 버튼. 상시 내비·하단 탭바 없음.

4개 화면(home/detail/cart/orders)을 하나의 순차적 흐름 4단계로 재해석했다 —
"둘러보기(탐색) → 상품 확인(상세) → 장바구니 확정 → 주문 완료/내역". 각 화면은
독립 HTML 이지만 상단 스텝 표시기 + 하단 이전/다음 버튼으로 스스로가 4단계 중
몇 번째인지 표시하고, 다음/이전 버튼은 인접 화면 파일로 이동한다.

보조 원형은 쓰지 않는다 — 네 화면 모두 wizard-flow 뼈대(단계 표시기 상단 +
한 칼럼 본문 + 하단 이전/다음)를 그대로 따른다.

## 성격 (personality)

**`elevated`** — scale: regular / surface: shadow / motion: expressive

- 이유: 대외 소비자용 구매 화면(사용 빈도가 낮고 1회성 체류가 짧은 커머스 흐름)이라
  터치 대상 위계를 그림자로 뚜렷하게 드러내고, 버튼 눌림·전환에 또렷한 모션을 줘서
  "다음 단계로 넘어갔다"는 피드백을 체감시키는 게 중요하다. 관리 화면처럼 밀도를
  높일 이유(장시간 응시·많은 데이터 비교)가 없어 `crisp`는 맞지 않고, `statement`의
  과장된 스케일은 소비자 구매 흐름에는 산만하다.

## 배제 목록 (최소 3, 근거 포함)

1. **하단 탭바 안 씀** — 모바일 커머스 앱이면 기본으로 까는 상시 하단 탭바(홈/검색/
   장바구니/마이)를 쓰지 않는다. wizard-flow 원형은 "상시 내비·탭바 없음"을 뼈대로
   강제하고, 현재 위치는 상단 스텝 표시기 하나로만 알려준다 — 탭바를 더하면 상시
   내비가 두 개가 되어 원형이 요구하는 단일 흐름이 깨진다.
2. **상품 카드 그리드 안 씀** — 모바일 커머스 홈이면 기본값인 2열 카드 그리드
   상품 목록을 쓰지 않는다. wizard 본문은 "현재 단계 하나를 한 칼럼으로"가 원칙이라
   그리드형 다중 비교 레이아웃은 단계 진행이라는 인지 모델과 어긋난다. 대신 세로
   한 줄 리스트(설명 행)로 배열해 "이번 단계에서 고를 것"을 순서대로 훑게 한다.
3. **사이드바 안 씀** — 390px 폭 모바일 화면에서 sidebar-app 뼈대는 애초에 맞지
   않고, wizard-flow 도 상시 내비를 두지 않으므로 이중으로 배제된다.
4. **케밥 메뉴(⋮ 액션 드롭다운) 안 씀** — 각 단계 화면의 조작을 "다음으로 진행 /
   이전으로 되돌아가기" 하나로 제한해야 wizard 흐름의 단순성이 유지된다. 상품 편집,
   주문 취소 등 부가 액션을 케밥 메뉴로 늘리면 단계 밖 선택지가 생겨 흐름이 흐려진다.

## 토큰 요약 (화면 코드에 인라인 선언)

시맨틱 이름만 사용, 하드코딩 색 없음.

- `--background` `--foreground` `--card` `--card-foreground`
- `--primary`(과일 그린) `--primary-foreground`
- `--secondary`(시트러스 오렌지) `--secondary-foreground`
- `--accent` `--accent-foreground` `--muted` `--muted-foreground`
- `--border` `--destructive` `--destructive-foreground`
- `--chart-1`~`--chart-5` (품목별 색 구분 — 참외/토마토/자두/수박/포도 계열)
- `--radius`, `--shadow-sm`, `--shadow-md` (elevated 성격 — 표면은 그림자로 위계 표현)

## 화면 ↔ 단계 매핑

| 파일 | 단계 | 제목 | 하단 버튼 |
| --- | --- | --- | --- |
| `home.html` | 1/4 탐색 | 이번 주 제철과일 | 이전 없음 · 다음 → 상세 |
| `detail.html` | 2/4 상품 | 성주 참외 2kg | 이전 → 홈 · 다음 → 장바구니 |
| `cart.html` | 3/4 장바구니 | 장바구니 확인 | 이전 → 상세 · 다음(주문하기) → 주문내역 |
| `orders.html` | 4/4 완료 | 주문 완료 · 주문내역 | 이전 없음 · "다음" 대신 "홈으로" |
