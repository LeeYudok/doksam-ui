# Evidence Decision Pattern — Design Brief

- Archetype: detail workbench inside a sidebar application. The user must compare several evidence items and make one accountable response choice without leaving the context.
- Personality: sober, compact, inspectable. The evidence column establishes trust; the decision column makes the human checkpoint obvious.
- Chosen navigation: no new local navigation. Evidence anchors connect an option back to its supporting records, while the surrounding application owns destination changes.
- Excluded: KPI-card dashboard as the primary surface, a generic approval modal, automatic recommendation execution, and an infinite activity feed. None lets a reviewer trace one selection to its evidence as directly.
- Responsive behavior: single column below `lg`; evidence remains before decisions so review order survives narrow screens.
